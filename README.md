## BARBERSHOP BOOKINGS SYSTEM
ระบบ BARBERSHOP BOOKINGS SYSTEM พัฒนาโครงสร้างเพื่อใช้ในการจัดเก็บข้อมูล วัน-เวลา ในการแสดงข้อมูลการจองของผู้ใช้โดยดึงข้อมูลจากระบบหลังบ้านที่ใช้ PHP ในการจัดการฐานข้อมูล MySQL

[ดูวิดีโอสาธิตระบบ](https://youtu.be/ujGFZfvSrD4?si=Dbq8AbQrQZPexqDM)

***

การทำงานหลัก
---
- ดึงข้อมูลบริการต่าง ๆ มาแสดงบนเว็บไซต์โดยใช้ข้อมูลจาก MySQL  
- ผู้ใช้สามารถเข้ามาเลือกบริการต่าง ๆ ในเว็บไซต์ และสามารถยกเลิกบริการตามวันเวลาที่กำหนด  
- ช่างบริการสามารถดูข้อมูลบริการของลูกค้าได้ และสามารถตอบรับบริการหรือยกเลิกได้ตามเวลาที่กำหนดเช่นกัน  
- ผู้ดูแลสามารถตรวจสอบข้อมูลของผู้ใช้งานทั้งสองประเภท และสามารถเพิ่มหรือลบข้อมูลต่าง ๆ ได้  


***

เครื่องมือที่ใช้
- Front-End: HTML, CSS, JavaScript  
- Back-End: PHP  
- Database: MySQL
