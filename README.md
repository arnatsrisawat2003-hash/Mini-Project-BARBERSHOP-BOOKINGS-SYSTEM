## BARBERSHOP BOOKINGS SYSTEM
ระบบ BARBERSHOP BOOKINGS SYSTEM พัฒนาโครงสร้างเพื่อใช้ในการจัดเก็บข้อมูล วัน-เวลา ในการแสดงข้อมูลการจองของผู้ใช้โดยดึงข้อมูลจากระบบหลังบ้านที่ใช้ PHP ในการจัดการฐานข้อมูล MySQL

[ดูวิดีโอสาธิตระบบ](https://youtu.be/ujGFZfvSrD4?si=Dbq8AbQrQZPexqDM)

***

การทำงานหลัก
---
-ดึงข้อมูลบริการต่างๆมาแสดงบนเว็บไซต์โดยใช้ ข้อมูลจาก MySQL
-ผู้ใช้สามารถเข้ามาเลือกบริการต่างๆในเว็บไซต์และสามารถยกเลิกบริการตามวันเวลาที่กำหนด
-ช่างบริการสามารถดูข้อมูลบริการของลูกค้าได้และสามารถที่จะตอบรับบริการหรือยกเลิกได้ตามเวลาที่กำหนดเช่นกัน
-ฝังผู้ดูแลสามารถเช็คข้อมูลทั้งสองประเภทของผู้ใช้งานได้และสามารถเพิ่มลบข้อมูลต่างๆได้

***

เครื่องมือที่ใช้
FrontEnd: HTML, CSS, JavaScript
Backend: PHP
Database: MySQL
