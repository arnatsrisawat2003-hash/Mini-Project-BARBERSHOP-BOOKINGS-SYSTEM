## BARBERSHOP BOOKINGS SYSTEM
ระบบ BARBERSHOP BOOKINGS SYSTEM พัฒนาโครงสร้างเพื่อใช้ในการจัดเก็บข้อมูล วัน-เวลา ในการแสดงข้อมูลการจองของผู้ใช้โดยดึงข้อมูลจากระบบหลังบ้านที่ใช้ PHP ในการจัดการฐานข้อมูล MySQL
